<a id="overview"></a>
## 🌐 Overview

<div align="center">

> ### "A university community should not need separate platforms for every part of campus life."

</div>

Students, teachers, alumni, and administrators often rely on disconnected tools — social media groups, messaging apps, notice boards, email, and one-off academic tools. **CampusConnect** merges all of it into a single, role-aware, community-focused ecosystem.

<div align="center">

| 🎓 Academics | 🗣️ Community | 🤝 Networking | 💼 Careers | 💬 Communication | 🎉 Campus Life | 🛡️ Governance |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| Materials, assignments, GPA/CGPA | Feed, notices, suggestions | Profiles, connections, directory | Alumni stories, mentorship, jobs | Private messaging + files | Events, Lost & Found, marketplace | Role-based admin & moderation |

</div>

<p align="center"><b>Learn · Communicate · Collaborate · Connect · Participate — all in one place.</b></p>

### 🔐 Authentication & Account Security

<details>
<summary><b>Expand feature list</b></summary>

<a id="installation--setup"></a>
## ⚙️ Installation & Setup

### Prerequisites

`XAMPP` · `PHP 8+` · `MySQL` · `phpMyAdmin` · `Git` · a modern browser

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Masum8823/campus_connect.git
cd campus_connect
```

### 2️⃣ Place the project in XAMPP

```text
C:\xampp\htdocs\campus_connect\
```

### 3️⃣ Start XAMPP

Open the XAMPP Control Panel and start **Apache** and **MySQL**.

### 4️⃣ Create the database

Open `http://localhost/phpmyadmin` → create a new database → import `database.sql` from the project root.

### 5️⃣ Configure the database connection

Update `config.php` with your local MySQL credentials.

> ⚠️ **Never commit** production credentials, SMTP passwords, API keys, or other secrets to GitHub.

### 6️⃣ Configure email service

CampusConnect uses **PHPMailer + Gmail SMTP** for OTP verification and event reminders. For production, prefer environment variables or a secrets manager over hardcoding.

### 7️⃣ Launch CampusConnect 🚀

```text
http://localhost/campus_connect/
```

<a id="security--access-control"></a>
## 🛡️ Security & Access Control

- Session-protected pages & role-based authorization
- Ownership verification on user-generated content
- OTP-based verification & password recovery
- Account activation controls
- Connection-based profile privacy & message request restrictions
- User blocking & secure conversation deletion validation
- Cascading database relationships & unique constraints
- Deadline validation for assignments, secure event ownership checks
- Administrative moderation across all user-facing modules

> **Production note:** further hardening recommended — CSRF protection, stricter upload validation, rate limiting, HTTPS enforcement, centralized input/output sanitization.
